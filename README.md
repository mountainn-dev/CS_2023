# CS2023 기반 CS 기초 독학 기록

ACM·IEEE-CS·AAAI가 공동 발표한 학부 컴퓨터과학 교육과정 권고안 **CS2023(Computer Science Curricula 2023)** 을 기준으로,
비전공 앱 개발자가 CS 기초를 체계적으로 채우기 위해 30주 동안 학습한 내용을 기록하는 저장소다.

## 왜 CS2023인가

CS2023은 "CS 학사 졸업생이 알아야 할 범위"를 17개 지식 영역(Knowledge Area)으로 정의한 문서다.
교과서가 아니라 **범위와 수준을 정하는 지도**이므로, 독학 범위를 빠짐없이 잡는 기준으로 삼았다.
시험 대비가 목적이 아니며, 특정 직무에 한정되지 않은 전반적인 기초를 목표로 한다.

## 학습 범위

CS2023의 17개 영역 중 기반이 되는 9개 영역을 다룬다. 나머지 영역(AI·HCI·그래픽스·보안 등)은 후속 과정으로 미룬다.

| 코드 | 영역 | 개념 수 |
|---|---|---:|
| SDF | Software Development Fundamentals | 49 |
| MSF | Mathematical and Statistical Foundations | 67 |
| AL | Algorithmic Foundations | 70 |
| FPL | Foundations of Programming Languages | 68 |
| AR | Architecture and Organization | 60 |
| OS | Operating Systems | 79 |
| NC | Networking and Communication | 68 |
| DM | Data Management | 91 |
| SE | Software Engineering | 93 |
| | **합계** | **645** |

## 30주 구성

영역을 순서대로 끝내는 대신, 선수 관계가 있는 영역을 매주 2~4개씩 병행하고 통합 과제로 연결을 확인한다.

| 블록 | 주차 | 주제 |
|---|---|---|
| A | 1~6주 | 프로그래밍·수학·알고리즘 기초 |
| B | 7~12주 | 프로그래밍 언어와 컴퓨터 구조 |
| C | 13~18주 | 운영체제와 네트워크 |
| D | 19~24주 | 데이터 관리와 소프트웨어 공학 |
| E | 25~30주 | 시스템 통합과 심화 연결 (분산 시스템·보안·성능 분석·종합 프로젝트) |

645개 개념은 각각 30주 중 한 주차에만 배정했다. 블록 E의 분산 시스템·보안 주제는 9개 영역 밖의 확장 학습으로 따로 표시한다.
주차는 진도 단위이며 달력 주와 다르다.

## 기록 방식

- 매주 해당 주차의 체크리스트를 보고 개념별로 학습 노트를 남긴다.
- 개념마다 아래 질문에 답할 수 있으면 체크한다.
  - 이 개념은 무엇이며 어떤 문제를 해결하는가?
  - 내부에서 어떤 단계와 자료구조를 거치는가?
  - 시간·공간·메모리·네트워크·운영 비용은 무엇인가?
  - 어떤 조건에서 올바르게 동작하고 어떤 조건에서 실패하는가?
  - 대안과 비교했을 때 장단점은 무엇인가?
  - 다른 CS 분야의 어떤 개념과 연결되는가?
- 주차 말에는 통합 과제 결과물(코드·도식·실험 기록)을 함께 남긴다.
