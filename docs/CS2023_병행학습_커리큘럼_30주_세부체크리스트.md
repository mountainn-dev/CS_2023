# CS2023 기반 병행 학습 커리큘럼 — 30주 세부 체크리스트

**30주 · 9개 필수 기반 분야 · 원본 개념 645개를 주차별 개별 체크박스로 배정**

> 이 문서는 `CS2023_필수기반_학습개념_체크리스트.md`의 645개 개념을 `CS2023_병행학습_커리큘럼_30주.md`의 30개 주차에 각각 한 번씩 배정한 것이다. 개념명은 원본 그대로이며, 각 주차의 병행 학습 과목·통합 과제·연결 관계도 원본 커리큘럼을 그대로 옮겼다.

공식 자료: [Knowledge Areas](https://csed.acm.org/knowledge-areas/) · [Final Report](https://csed.acm.org/final-report/)

## 사용 규칙

- **세부 체크리스트**의 체크박스가 공식 배정이다. 개념 하나는 30주 중 정확히 한 주차에만 나타난다.
- `[확장]` 표시가 붙은 체크박스는 원본 9개 분야 목록에 없는 확장 주제(PDC·SEC·분산 시스템 등)이며, 645개 집계에 포함하지 않는다.
- **복습** 줄은 이전 주차에 공식 배정된 개념을 다시 보는 안내이며 체크박스가 아니다. 공식 배정과 중복 집계하지 않는다.
- 주차는 진도 단위이며 달력 주가 아니다. 항목 수가 많은 주차(네트워크·SE 주차 등)는 2주로 나눠도 된다.
- 세부 체크리스트 항목은 `분야 코드 — 원본 하위 영역` 단위로 묶었고, 분야 순서는 원본 체크리스트의 01~09 순서를 따른다.
