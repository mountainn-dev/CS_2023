# CS2023 기반 병행 학습 커리큘럼

**30주 · 9개 필수 기반 분야 · 주제 연결형 독학 계획**

## 운영 원칙

- 기존 필수 기반 9개 분야(SDF, MSF, AL, FPL, AR, OS, NC, DM, SE)를 연결해 학습한다.
- 주차는 진도 단위이며 고정된 달력 주가 아니다. 학습 시간과 깊이에 따라 늘리거나 줄인다.
- 매주 2~4개 학습 트랙을 병행하고, 통합 과제로 개념 간 연결을 확인한다.
- 이번 과정은 필수 기반 9개 분야에 초점을 둔다. 나머지 CS2023 분야는 후속 과정에서 추가한다.

## 주간 학습 리듬 예시

- 세션 A — 주력 개념 학습 및 도식화
- 세션 B — 연결 과목 학습
- 세션 C — 수학·코드·실험으로 검증
- 세션 D — 자료 없이 회상하고 분야 간 연결 기록

## 블록 A — 프로그래밍·수학·알고리즘 기초 (1~6주)

### 01주차 — 프로그램·논리·복잡도 입문

**병행 학습 과목**
- [ ] SDF: 변수·자료형·표현식·제어 흐름·함수·스코프·예외
- [ ] MSF: 명제 논리·진리표·논리적 동치·집합 연산
- [ ] AL: 추상 자료형(ADT)·알고리즘 명세·시간/공간 복잡도 기초

**통합 과제:** 프로그램을 작은 함수로 분해하고 입력·출력·경계 조건을 명시한다. 간단한 반복문과 탐색의 연산 횟수를 세어 본다.

**연결 관계:** SDF ↔ AL: 코드 구조와 알고리즘 단계 연결 / MSF → AL: 논리식과 정확성 설명

### 02주차 — 집합·함수·기본 자료구조

**병행 학습 과목**
- [ ] SDF: 배열·문자열·레코드/튜플·리스트·스택·큐 사용
- [ ] MSF: 관계·함수·단사/전사·합성 함수·수학적 귀납법 기초
- [ ] AL: 배열·연결 리스트·스택·큐·덱의 연산과 비용

**통합 과제:** 같은 문제를 배열과 연결 리스트로 구현하고 삽입·탐색 비용을 비교한다. 스택·큐의 불변 조건을 적는다.

**연결 관계:** MSF → AL: 귀납적 사고와 자료구조 불변 조건 / SDF ↔ AL: 구현과 추상 자료형

### 03주차 — 정수·이진 표현·재귀

**병행 학습 과목**
- [ ] SDF: 재귀 호출·매개변수 전달·오류와 스택 트레이스
- [ ] MSF: 정수 나눗셈·나머지·최대공약수·모듈러 산술
- [ ] AR: 2진수·16진수·부호 있는 정수·2의 보수·오버플로
- [ ] AL: 재귀 알고리즘과 재귀 호출 비용

**통합 과제:** 유클리드 알고리즘을 반복·재귀 방식으로 작성하고, 정수 오버플로와 재귀 깊이를 실험한다.

**연결 관계:** MSF ↔ AL: 유클리드 알고리즘 / AR ↔ SDF: 자료형 범위와 런타임 결과

### 04주차 — 증명·정렬·탐색

**병행 학습 과목**
- [ ] MSF: 직접 증명·대우·모순 증명·귀납법·반례
- [ ] AL: 선형/이진 탐색·삽입/선택 정렬·병합 정렬·퀵 정렬
- [ ] SDF: 테스트 케이스·경계 조건·단위 테스트

**통합 과제:** 이진 탐색의 전제 조건을 증명하고 정렬·탐색 알고리즘을 테스트한다. 평균·최악 사례를 비교한다.

**연결 관계:** MSF → AL: 정확성 증명 / SDF ↔ AL: 테스트와 알고리즘의 경계 조건

### 05주차 — 확률·조합·해시

**병행 학습 과목**
- [ ] MSF: 합·곱 법칙·순열/조합·비둘기집 원리·조건부 확률
- [ ] AL: 해시 함수·충돌·체이닝·개방 주소법·로드 팩터
- [ ] SDF: 맵·셋·컬렉션 API의 추상적 사용

**통합 과제:** 해시 충돌 사례를 만들고 적재율에 따른 탐색 비용을 관찰한다. 확률적 관점으로 충돌을 설명한다.

**연결 관계:** MSF ↔ AL: 해시 충돌과 확률 / SDF ↔ AL: 인터페이스 사용과 내부 구현 구분

### 06주차 — 1차 통합·개발 도구

**병행 학습 과목**
- [ ] SDF: Git·브랜치·충돌 해결·디버거·명령줄·패키지 관리
- [ ] MSF: 점화식·그래프·트리·확률 변수·기댓값 기초
- [ ] AL: 트리·힙·우선순위 큐·DFS/BFS 기초

**통합 과제:** 작은 자료구조 프로젝트를 구현하고 테스트·README·Git 이력을 남긴다. 트리 순회와 BFS/DFS를 시각화한다.

**연결 관계:** MSF ↔ AL: 트리·그래프 모델 / SDF: 재현 가능한 개발 작업 흐름


## 블록 B — 프로그래밍 언어와 컴퓨터 구조 (7~12주)

### 07주차 — 타입·메모리·언어 실행

**병행 학습 과목**
- [ ] FPL: 정적/동적 타입·타입 검사·타입 추론·타입 안전성
- [ ] AR: 레지스터·CPU·명령어 사이클·메모리 계층 개요
- [ ] SDF: 값·참조·객체 생명주기와 디버깅

**통합 과제:** 같은 자료 표현을 여러 언어로 비교하고, 컴파일 오류·런타임 오류·타입 오류를 분류한다.

**연결 관계:** FPL ↔ AR: 고급 언어와 기계 실행의 추상화 계층

### 08주차 — 스코프·클로저·함수형 사고

**병행 학습 과목**
- [ ] FPL: 정적 스코프·렉시컬 환경·바인딩·클로저·평가 순서
- [ ] FPL: 일급 함수·고차 함수·람다·순수 함수·부작용·불변성
- [ ] MSF: 함수·관계·귀납적 정의 복습

**통합 과제:** 클로저와 고차 함수 예제를 작성하고, 가변 상태가 결과에 미치는 영향을 비교한다.

**연결 관계:** FPL ↔ MSF: 함수 개념 / FPL ↔ SDF: 함수 추상화와 테스트 용이성

### 09주차 — 객체지향·타입 설계

**병행 학습 과목**
- [ ] FPL: 캡슐화·상속·합성·다형성·동적 디스패치·인터페이스
- [ ] FPL: 제네릭·서브타이핑·공변성/반공변성/불변성·널 가능성
- [ ] SE: 추상화·정보 은닉·모듈화·응집도·결합도

**통합 과제:** 작은 도메인 모델을 설계하고 상속과 합성, 인터페이스 기반 설계를 비교한다.

**연결 관계:** FPL ↔ SE: 언어 기능과 설계 원칙 / 타입 시스템 ↔ API 계약

### 10주차 — 컴파일러·런타임·메모리 관리

**병행 학습 과목**
- [ ] FPL: 토큰·문법·AST·파싱·컴파일 단계·바이트코드·JIT/AOT
- [ ] FPL: 스택/힙·참조 카운팅·추적 GC·메모리 누수·댕글링 참조
- [ ] AR: 기계어·어셈블리·함수 호출·스택 프레임

**통합 과제:** 간단한 프로그램의 소스→중간 표현/바이트코드→실행 흐름을 추적하고 스택 프레임을 그린다.

**연결 관계:** FPL ↔ AR: 언어 구현과 ISA / 메모리 관리 ↔ OS: 주소 공간의 구분

### 11주차 — 디지털 논리와 CPU 구조

**병행 학습 과목**
- [ ] AR: 논리 게이트·불 대수·조합/순차 회로·플립플롭·FSM
- [ ] AR: ALU·제어 장치·데이터 경로·명령어 인출/해독/실행
- [ ] MSF: 논리·상태 전이·증명 개념 복습

**통합 과제:** 간단한 FSM을 설계하고 명령어 실행 단계를 그림으로 설명한다.

**연결 관계:** MSF ↔ AR: 논리와 상태 기계 / AR: 소프트웨어 명령이 하드웨어 동작으로 이어지는 과정

### 12주차 — 캐시·성능·2차 통합

**병행 학습 과목**
- [ ] AR: 캐시 적중/미스·지역성·매핑·쓰기/교체 정책·메모리 대역폭
- [ ] AL: 정렬·탐색 복잡도·시간-공간 트레이드오프·상각 분석 기초
- [ ] SDF: 벤치마크·프로파일링 기초·재현 가능한 실험

**통합 과제:** 자료 접근 패턴을 바꿔 성능 차이를 관찰하고, 알고리즘 복잡도와 실제 측정 결과의 차이를 기록한다.

**연결 관계:** AR ↔ AL: 캐시 지역성과 알고리즘 성능 / SDF: 측정과 추측 구분


## 블록 C — 운영체제와 네트워크 (13~18주)

### 13주차 — 운영체제 구조·프로세스

**병행 학습 과목**
- [ ] OS: 커널/사용자 공간·시스템 콜·인터럽트·프로세스 상태·PCB
- [ ] OS: 프로세스 생성/종료·컨텍스트 스위치·프로세스 격리
- [ ] AR: 인터럽트·예외·함수 호출 규약 복습

**통합 과제:** 프로그램 실행부터 시스템 콜을 거쳐 커널 기능을 호출하는 흐름을 그린다.

**연결 관계:** AR ↔ OS: 하드웨어 예외와 운영체제 처리 / FPL ↔ OS: 런타임과 프로세스

### 14주차 — 스레드·스케줄링·동시성

**병행 학습 과목**
- [ ] OS: 스레드·사용자/커널 스레드·멀티스레딩 모델
- [ ] OS: CPU 스케줄링·선점/비선점·라운드 로빈·기아·에이징
- [ ] OS: 경쟁 상태·임계 영역·원자성·가시성·순서 보장

**통합 과제:** 간단한 공유 카운터 경쟁 상태를 재현하고 스케줄링 알고리즘의 대기·응답 시간을 계산한다.

**연결 관계:** FPL ↔ OS: 언어의 동시성 기능과 OS 스레드 / AL ↔ OS: 실행 비용

### 15주차 — 동기화·교착 상태·메모리

**병행 학습 과목**
- [ ] OS: 뮤텍스·세마포어·조건 변수·모니터·원자 연산/CAS
- [ ] OS: 생산자-소비자·교착 상태·라이브락·기아
- [ ] OS: 주소 변환·연속 할당·단편화·페이징·페이지 테이블·TLB

**통합 과제:** 생산자-소비자 문제를 의사코드로 작성하고 교착 상태의 필요 조건을 사례에 표시한다.

**연결 관계:** MSF ↔ OS: 상태·불변 조건 / AR ↔ OS: 주소와 메모리 계층

### 16주차 — 가상 메모리·파일·입출력

**병행 학습 과목**
- [ ] OS: 가상 메모리·페이지 폴트·요구 페이징·페이지 교체·스래싱
- [ ] OS: 파일 시스템·디렉터리·파일 디스크립터·inode·저널링
- [ ] OS: 버퍼링·캐싱·디바이스 드라이버·DMA

**통합 과제:** 가상 주소 변환과 파일 읽기 과정을 추적한다. 페이지 교체 알고리즘을 작은 참조열에 적용한다.

**연결 관계:** AR ↔ OS: 캐시와 가상 메모리 / OS ↔ DM: 파일 저장과 DB 저장 구분

### 17주차 — 네트워크 계층·IP

**병행 학습 과목**
- [ ] NC: OSI/TCP-IP·캡슐화·Ethernet·MAC·스위칭
- [ ] NC: IPv4/IPv6·서브넷·CIDR·라우팅·NAT·ICMP·DHCP
- [ ] MSF: 이진수·논리 연산·집합/주소 범위 복습

**통합 과제:** IP 주소와 서브넷을 계산하고, 한 호스트에서 다른 호스트로 패킷이 전달되는 경로를 그린다.

**연결 관계:** AR/MSF ↔ NC: 비트 표현과 주소 계산 / OS ↔ NC: 네트워크 인터페이스와 소켓 개념

### 18주차 — TCP·DNS·HTTP·TLS

**병행 학습 과목**
- [ ] NC: TCP/UDP·포트·핸드셰이크·재전송·흐름/혼잡 제어
- [ ] NC: DNS·HTTP 요청/응답·상태 코드·쿠키·캐시·웹소켓
- [ ] NC: TLS·인증서·HTTPS·프록시·로드 밸런서의 기초
- [ ] OS: 소켓과 IPC 복습

**통합 과제:** DNS 조회부터 TCP 연결, TLS 협상, HTTP 요청까지 순서를 설명하고 패킷 캡처를 읽는다.

**연결 관계:** OS ↔ NC: 소켓 API와 전송 계층 / SEC ↔ NC: TLS와 인증서 / SE ↔ NC: 타임아웃 설계


## 블록 D — 데이터 관리와 소프트웨어 공학 (19~24주)

### 19주차 — 관계형 모델·ER·SQL

**병행 학습 과목**
- [ ] DM: DBMS·스키마/인스턴스·관계형 모델·키·무결성 제약
- [ ] DM: 엔터티·속성·관계·ER 다이어그램·카디널리티
- [ ] DM: SQL DDL/DML·SELECT·WHERE·JOIN·집계

**통합 과제:** 작은 도메인의 ER 다이어그램을 작성하고 SQL로 조회한다. NULL과 3값 논리를 테스트한다.

**연결 관계:** MSF ↔ DM: 관계와 집합 연산 / SE ↔ DM: 요구사항을 데이터 모델로 변환

### 20주차 — 정규화·인덱스·쿼리 처리

**병행 학습 과목**
- [ ] DM: 함수 종속성·키·1NF/2NF/3NF/BCNF·분해
- [ ] DM: 페이지/레코드·B+Tree·해시 인덱스·복합/커버링 인덱스
- [ ] DM: 실행 계획·선택도·비용 기반 최적화

**통합 과제:** 비정규화된 테이블을 분해하고, 인덱스 전후 쿼리 계획과 비용을 비교한다.

**연결 관계:** AL ↔ DM: 트리·해시 자료구조 / AR ↔ DM: 페이지·캐시·I/O 비용

### 21주차 — 트랜잭션·동시성·복구

**병행 학습 과목**
- [ ] DM: 트랜잭션·ACID·커밋/롤백·격리 수준·동시 실행 이상
- [ ] DM: 잠금·2PL·데드락·MVCC·낙관적/비관적 제어
- [ ] DM: WAL·UNDO/REDO·체크포인트·백업/복원

**통합 과제:** 동시에 실행되는 트랜잭션의 이상 현상을 표로 재현하고, 격리 수준별 결과를 비교한다.

**연결 관계:** OS ↔ DM: 잠금과 동시성 / SE ↔ DM: 트랜잭션 경계와 실패 처리

### 22주차 — 소프트웨어 요구사항·설계

**병행 학습 과목**
- [ ] SE: 기능/비기능 요구사항·유스케이스·수용 기준·추적성
- [ ] SE: 추상화·정보 은닉·응집도·결합도·SOLID
- [ ] SE: 계층형·육각형·MVC/MVP/MVVM·UML·ADR

**통합 과제:** 작은 시스템의 요구사항과 아키텍처 결정 기록을 작성하고, 모듈 경계를 설계한다.

**연결 관계:** FPL ↔ SE: 타입·인터페이스와 설계 / DM ↔ SE: 도메인 모델과 영속성

### 23주차 — 테스트·리팩터링·디자인 패턴

**병행 학습 과목**
- [ ] SE: 단위/통합/시스템/인수·회귀 테스트
- [ ] SE: 경계값·동등 분할·상태 전이·테스트 더블·커버리지의 한계
- [ ] SE: 리팩터링·코드 스멜·Factory/Strategy/Observer/Adapter 등 패턴

**통합 과제:** 기존 구현에 테스트를 추가한 뒤 구조를 리팩터링한다. 패턴을 적용하기 전후의 복잡도와 변경 비용을 비교한다.

**연결 관계:** SDF ↔ SE: 디버깅과 테스트 / FPL ↔ SE: 다형성과 Strategy/Observer

### 24주차 — 빌드·버전 관리·CI/CD

**병행 학습 과목**
- [ ] SDF: Git·브랜치·충돌·패키지 의존성 복습
- [ ] SE: 시맨틱 버저닝·재현 가능한 빌드·CI·지속적 전달/배포
- [ ] SE: 환경 설정·배포 전략·롤백·DB 마이그레이션

**통합 과제:** 작은 프로젝트에 자동 테스트와 빌드 파이프라인을 구성하고, 실패한 배포를 롤백하는 절차를 문서화한다.

**연결 관계:** SE ↔ SDF: 개발 도구와 품질 자동화 / DM ↔ SE: 스키마 변경과 배포


## 블록 E — 시스템 통합과 심화 연결 (25~30주)

### 25주차 — 분산 시스템 입문·장애 모델

**병행 학습 과목**
- [ ] PDC 성격의 확장: 동시성/병렬성·공유 메모리·메시지 전달
- [ ] NC: 지연·패킷 손실·타임아웃·연결 끊김
- [ ] SE: 로그·메트릭·트레이스·장애 대응·근본 원인 분석

**통합 과제:** 네트워크 요청 실패를 타임아웃·서버 오류·응답 유실로 나눠 처리 전략을 설계한다.

**연결 관계:** OS ↔ NC ↔ SE: 실행·통신·운영 관점 연결

### 26주차 — 복제·캐시·일관성

**병행 학습 과목**
- [ ] DM: 복제·복제 지연·샤딩·파티셔닝·OLTP/OLAP 개요
- [ ] 분산 시스템: 부분 실패·일관성 모델·CAP 개요
- [ ] SE: 멱등성·재시도·중복 요청·캐시 무효화

**통합 과제:** 중복 요청과 늦게 도착한 응답이 데이터를 어떻게 망가뜨리는지 사례를 만들고, 멱등성 키와 재시도 정책을 설계한다.

**연결 관계:** DM ↔ NC: 복제 지연과 네트워크 / SE ↔ DM: 데이터 일관성과 오류 복구

### 27주차 — 보안 기초와 안전한 통신

**병행 학습 과목**
- [ ] SEC 확장: CIA·위협 모델·공격 표면·최소 권한
- [ ] SEC: 대칭키·공개키·해시·MAC·서명·인증서·PKI
- [ ] NC: TLS·HTTPS·인증서 검증 복습
- [ ] SE: 비밀 정보 관리·보안 테스트 기초

**통합 과제:** 간단한 위협 모델을 작성하고, 해시·암호화·서명의 목적을 구분한다. HTTPS에서 인증서 검증이 필요한 이유를 설명한다.

**연결 관계:** MSF ↔ SEC: 확률과 위험 / NC ↔ SEC: 프로토콜과 신뢰 / SE ↔ SEC: 개발 수명주기

### 28주차 — 신뢰성·성능·시스템 분석

**병행 학습 과목**
- [ ] AR: Amdahl의 법칙·캐시·병렬 처리·성능 지표 복습
- [ ] OS: 스케줄링·메모리·I/O 병목 복습
- [ ] NC/DM: 지연 시간·처리량·실행 계획·캐시·복제 지연
- [ ] SE: SLI/SLO/SLA·장애 사후 분석

**통합 과제:** 하나의 성능 문제를 CPU·메모리·네트워크·DB·애플리케이션 계층으로 나누어 진단 계획을 작성한다.

**연결 관계:** AR ↔ OS ↔ NC ↔ DM: 병목이 계층을 가로질러 전파되는 방식

### 29주차 — 비관계형 데이터·언어·알고리즘 심화 연결

**병행 학습 과목**
- [ ] DM: 키-값·문서·와이드 컬럼·그래프 DB·데이터 웨어하우스·ETL/ELT
- [ ] FPL: 정적 분석·데이터 흐름·최적화 복습
- [ ] AL: 탐욕법·동적 계획법·백트래킹·NP-완전성 개요

**통합 과제:** 요구 조건에 따라 저장 모델과 알고리즘 전략을 선택하고, 선택 근거와 비용을 문서화한다.

**연결 관계:** AL ↔ DM: 데이터 모델과 접근 패턴 / FPL ↔ SE: 정적 분석과 코드 품질

### 30주차 — 종합 프로젝트·개념 지도 완성

**병행 학습 과목**
- [ ] 전체: SDF·MSF·AL·FPL·AR·OS·NC·DM·SE의 핵심 개념 복습
- [ ] 통합: 요구사항→설계→자료구조/알고리즘→DB→네트워크→운영체제→테스트/배포
- [ ] 운영: 로그·메트릭·장애 분석·보안 검토

**통합 과제:** 작은 클라이언트-서버 시스템을 설계하거나 기존 프로젝트를 분석한다. 아키텍처 그림, 데이터 모델, API 흐름, 테스트, 성능/장애 시나리오, 보안 체크리스트를 산출물로 남긴다.

**연결 관계:** 모든 분야를 하나의 시스템 안에서 연결하고, 이해가 얕은 개념을 다음 심화 학습 목록으로 분리
